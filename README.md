# news.info

বাংলা ভাষায় স্বয়ংক্রিয় খবরের সাইট। দেশি ও বিদেশি সংবাদমাধ্যম থেকে খবরের শিরোনাম, ছোট সারাংশ এবং মূল সোর্সের লিংক এক জায়গায় দেখায়।

**লাইভ সাইট:** https://newsinfo-ems.pages.dev

## কোন কাজে কোন সেবা

| কাজ | সেবা |
|---|---|
| সাইট রাখা (হোস্টিং) | Cloudflare Pages |
| খবর আনা ও সাজানো | Cloudflare Worker |
| খবরের ডাটাবেস | Supabase |
| খেলার খবর বাংলায় অনুবাদ | Cloudflare Workers AI |
| কোড রাখা | GitHub |

## ফিচার

- বর্তমান, আন্তর্জাতিক ও খেলাধুলা (ক্রিকেট/ফুটবল) ট্যাব
- প্রতি মিনিটে নতুন খবর আসে
- ফোনে অ্যাপের মতো ইনস্টল করা যায় (PWA)
- অ্যাডমিন প্যানেল

## কপিরাইট নিয়ম

শুধু শিরোনাম, ছোট সারাংশ ও মূল সোর্সের লিংক দেখানো হয়। পুরো খবর কপি করা হয় না।
